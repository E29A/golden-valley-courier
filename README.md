Golden Valley Courier is a complete offline flight game: fly an amber stunt-mail plane through a golden-hour valley, thread the rings and land on Runway 27. Three missions (Ring Run, Canyon Slalom, Precision Landing), an arcade flight model with throttle, bank, stall and ground effect, fuel and airframe damage, chase / cockpit / nose cameras, a full HUD (altitude, speed, heading, horizon) and synthesised WebAudio engine, wind and ring chimes. Keyboard and mouse, desktop browser, no network needed.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```

Or open `game/index.html` directly from the files on disk.

Controls: W/S throttle, arrow keys fly, C camera, P pause, 1/2/3 mission, R restart, M mute.
